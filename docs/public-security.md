# Защита открытого генератора

Область изменений: публичные bootstrap/preview и гостевая главная. Сохранение размещений, выпуск QR, реестр, карточки, расшифровка и управление сохраняют отдельную авторизацию WordPress и capabilities. Публичный обработчик не записывает данные и использует только статические запросы каталога.

## Проверка запроса

- Только POST и точный маршрут `?action=cargo_public_generator`.
- Форма `application/x-www-form-urlencoded`, HTTP-запрос до 64 KiB, поле JSON до 16 KiB, глубина JSON до 16.
- Структура JSON — объект, только перечисленные поля. Для каталога — пустой объект. Параметры размещения — отдельный объект с полями выбранного носителя.
- Названия и метки — строки корректного UTF-8 с пределами длины. Управляющие ASCII-символы запрещены. ID и год проверяются без обрезания произвольной строки до числа. Переключатели принимают только boolean/0/1.
- Требуется nonce WordPress. Заголовки Origin и Sec-Fetch-Site проверяются: браузерные запросы с другого сайта отклоняются. Отсутствие этих заголовков не означает авторизацию; публичный read-only API остаётся доступен клиентам без браузера.
- Неверный JSON даёт нейтральную ошибку. Неожиданные ошибки дают общий ответ; пользовательский ввод в журнал не записывается обработчиком.

## Спецсимволы и URL

Строки не кодируются в HTML при приёме. Кавычки, амперсанды и текст вроде `<img ...>` остаются данными: интерфейс использует `textContent`/`value`, серверная HTML-оболочка — контекстное экранирование, JSON-конфигурация — JSON_HEX-флаги. Это предотвращает двойное кодирование и сохраняет настоящие значения меток.

UTM кодируются в URL через percent-encoding; допустимые рекламные макросы Roistat сохраняются отдельно. Назначение — абсолютный HTTPS URL с портом 443 и точным разрешённым доменом, без credentials, управляющих символов и обратных слешей. Генератор не скачивает указанный URL.

Гостевая главная получает CSP: скрипты и соединения только self, запрет inline-обработчиков, object/base/frames, формы только self. Inline CSS разрешён для совместимости оформления WordPress; inline JavaScript и eval не разрешены. Также выдаются nosniff, X-Frame-Options DENY и запрет камеры/микрофона/геолокации.

Черновик sessionStorage считается недоверенным: ограничены размер, срок, типы и длины; восстанавливаются только разрешённые поля. Произвольные вложенные значения и ключи `__proto__` не попадают в состояние формы.

## Проверка и применение

Локально `scripts/check.sh` прошёл: 122 сценария публичного API, прежние доменные/приватные проверки, CSP-политика, восстановление изменённого черновика, вывод XSS/SQL-подобного текста и синтаксис. Поддельная БД запрещает любые записи и чтение внутренних таблиц. IDN-пример пропущен из-за отсутствия intl в локальном PHP.

Это не полноценный пентест. Контейнерные HTTP-проверки, реальное исполнение CSP браузером и нагрузочные проверки ещё не выполнены. `tests/http.py` дополнен проверками CSP, типов и размера публичного запроса; запускать после пересборки при наличии предыдущих fixtures.

Для применения из существующего PuTTY: пересобрать wordpress, обновить wordpress и пересоздать nginx. Из среды агента Docker недоступен.

После обновления в приватном окне проверить:

1. Обычный онлайн/офлайн-предпросмотр и шаблон «Сайт» работают, Roistat-макросы сохраняются.
2. Название `O'Reilly & Партнёры` и текст `<img src=x onerror=alert(1)>` в необязательной UTM-метке выводятся текстом, код не исполняется. В скопированном URL спецсимволы закодированы.
3. Сторонний домен и javascript URL отвергаются, закрытые разделы ведут на вход.
4. CSP присутствует в ответе главной; проверить консоль браузера и загрузку app.js, CSS и шрифтов. WordPress inline-скрипты темы могут блокироваться; интерфейс приложения использует внешний app.js.

Существующий origin rate-limit сохранён. За внешним reverse proxy его ключ может быть общим адресом прокси: это ограничение общей нагрузки, не доказанная индивидуальная защита каждого посетителя. Гостевой nonce публичен и не заменяет антибот-защиту. Периметр сервера и обновление WordPress/зависимостей не менялись этим исправлением.
